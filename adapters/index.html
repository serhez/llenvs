    Adapters¶

    llenvs wraps 17+ environment libraries through a unified adapter interface. Each adapter translates a third-party library's API into llenvs Environment protocol.

    • ReasoningGym

      Procedural reasoning tasks with automatic answer extraction.

      ReasoningGym

    • HuggingFace

      AIME, GSM8K, and other HF datasets as evaluation environments.

      HuggingFace

    • GEM

      Multi-turn games and benchmarks with tool support.

      GEM

    • Gymnasium

      Classic RL environments — Gym4Real, MarsExplorer, and custom.

      Gymnasium

    • WebShop

      E-commerce product search and purchase environment.

      WebShop

    • AlfWorld

      Text-based household task environments.

      AlfWorld

    • Jericho

      50+ classic interactive fiction text adventure games.

      Jericho

    • AgentGym

      15 multi-turn agent environments via client-server architecture.

      AgentGym

    • LMRL-Gym

      Multi-turn text environments — Wordle, Chess, Maze, and more.

      LMRL-Gym

    • Aviary

      FutureHouse tool-calling environments for scientific tasks.

      Aviary

    • Verifiers

      Single-turn and tool environments with rubric scoring.

      Verifiers

    • OpenEnv

      Session-based server environments with MCP tool support.

      OpenEnv

    • SciAgentGYM

      Multi-step scientific tool-use across 6 domains.

      SciAgentGYM

    • InterCode

      Interactive code generation in Bash, SQL, Python, CTF.

      InterCode

    • MARE

      Meta Agents Research Environments (Gaia2 benchmark).

      MARE

    • tau2

      Multi-turn customer service benchmark — airline, retail, telecom.

      tau2

    • Craftax

      JAX-based open-ended survival benchmark with text, symbolic, and pixel modes.

      Craftax
